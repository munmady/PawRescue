# 02 · Scope

## Scope principle

> **Every feature must support the core mission: help an animal in distress.** Report → Respond → Treat → Outcome.

The portfolio build is the MVP plus a demo mode. Adoption and product-based food donations are secondary. FUTURE ARCHITECTURE is documented, not built. Build classes: **REAL PROTOTYPE**, **SIMULATED DEMO**, **FUTURE ARCHITECTURE** (see [01-product.md](01-product.md#prototype-classification)).
